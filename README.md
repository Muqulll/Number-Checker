# Number-Checker in JS
Check a Number whether it is a Positive, Negative, Zero, Even or Odd Number with just a simple js function which is comprised of other modular functions such as:
- isPositive
- isNegative
- isZero
- isEven (this also handles the Odd Numbers with a clever trick instead of making another one for odd numbers)

**this project was mainly a project for roadmap.sh**
